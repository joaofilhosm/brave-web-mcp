Brave Web MCP

Servidor MCP stateless para busca em tempo real na internet, com a Brave Search API e fallback automatico para o DuckDuckGo. Le paginas e extrai conteudo em Markdown. Roda em serverless na Vercel.

Endpoint

Configure o cliente MCP apontando para esta URL (transporte Streamable HTTP):

{
  "mcpServers": {
    "brave-web": {
      "type": "http",
      "url": "https://SEU-DOMINIO.vercel.app/mcp"
    }
  }
}

Tools disponíveis

  • web_searchBusca na web, notícias, imagens e vídeos. Brave primeiro, DuckDuckGo como fallback. Filtros de idioma, país e recência.
  • web_contextBusca e extrai excertos das próprias páginas, grounding com fonte em uma chamada.
  • web_fetchLê uma URL e retorna o conteúdo principal em Markdown, sem scripts, nav ou rodapé.
  • search_and_readBusca e lê os melhores resultados em uma única chamada.

Segurança

O web_fetch valida cada redirecionamento contra redes privadas, loopback e metadata de cloud (proteção SSRF), e resolve o DNS novamente no momento da conexão para bloquear DNS rebinding.
